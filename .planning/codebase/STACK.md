# Technology Stack

**Analysis Date:** 2026-08-19 (v1.0 shipped)

## Languages

**Primary:**
- Dart — all application logic, UI, scene rendering, and audio synthesis (`lib/`, 29 files, ~3,874 LOC)

**Secondary:**
- Kotlin — Android embedding, generated by Flutter and unmodified (`android/app/src/main/kotlin/`)
- Kotlin DSL / Gradle — Android build and release signing (`android/app/build.gradle.kts`)
- HTML — the privacy policy page served from `docs/index.html` (static, hand-written)
- HTML/CSS/JS — Flutter's generated web bootstrap in `web/` (scaffold only; web is not a v1 target)

## Runtime

**Environment:**
- Flutter SDK, stable channel — developed and verified against Flutter 3.44.5 / Dart 3.12.2
- Declared constraint in `pubspec.yaml`: `sdk: ^3.10.7`

**Package Manager:**
- Pub
- Lockfile: `pubspec.lock` (committed)

## Frameworks

**Core:**
- Flutter — UI framework
- Material Design 3 — used only as the app shell (`MaterialApp`, `Scaffold`, `Navigator`,
  `showModalBottomSheet`). The visual language is *not* Material: colors, typography,
  radii, and shadows all come from `lib/theme/app_tokens.dart`, driven by `design/README.md`.
  `ColorScheme.fromSeed` is seeded from `AppTokens.accent` purely so Material's own
  internals have a coherent palette.

**Testing:**
- `flutter_test` — unit and widget tests; also the rendering host for the headless asset
  generators in `test/tool/`

**Build/Dev:**
- `flutter_lints` 6.0.0 — analyzer rules, activated via `analysis_options.yaml`
- `flutter_launcher_icons` 0.14.4 — generates the Android adaptive-icon mipmap set from
  `assets/icon/icon_foreground.png` + `icon_background.png`; configured in `pubspec.yaml`

## Key Dependencies

**Runtime (direct):**
- `provider` ^6.1.5+1 — the only state-management dependency; supplies
  `ChangeNotifierProvider` / `context.watch` over `TimerController`
- `wakelock_plus` ^1.6.1 — keeps the screen awake while a timer runs; imported by exactly
  one file, `lib/timer/wakelock_screen_wake.dart`
- `shared_preferences` ^2.5.5 — persists last-used duration, scene, and mute choice;
  imported by exactly one file, `lib/settings/setup_preferences.dart`
- `audioplayers` ^6.8.1 — plays the completion chime from in-memory synthesized bytes;
  imported by exactly one file, `lib/audio/audioplayers_chime_player.dart`
- `cupertino_icons` ^1.0.8 — scaffold leftover; the app ships no Cupertino icons

**Dev (direct):**
- `flutter_test` (SDK), `flutter_lints` ^6.0.0, `flutter_launcher_icons` ^0.14.4

**Notably absent by design:**
- No HTTP client, no backend SDK, no analytics, no crash reporting, no ad SDK — the app
  makes no network calls at all
- No `google_fonts` — both font families are bundled offline as static instances
- No image/animation asset pipeline (no Lottie, Rive, or SVG) — every scene is drawn with
  `CustomPainter` from shape primitives
- No audio asset — the chime is synthesized as WAV bytes in pure Dart
  (`lib/audio/chime_synth.dart`)
- No code generation, no build_runner, no freezed/json_serializable

## Configuration

**Environment:**
- No environment variables, no `.env` file. The app has no configurable runtime surface.

**Build:**
- `pubspec.yaml` — dependencies, version (`1.0.0+1`), bundled fonts, `flutter_launcher_icons` config
- `analysis_options.yaml` — analyzer/linter configuration
- `pubspec.lock` — locked dependency versions

**Bundled assets:**
- `assets/fonts/` — Baloo 2 Bold (wordmark only) and Quicksand 400/500/600/700, extracted
  as static instances from the upstream variable fonts so the app works fully offline
- `assets/icon/` — launcher icon foreground/background layers, themselves generated from
  the app's own painters by `test/tool/generate_launcher_icon_test.dart`

**Platform-Specific:**
- `android/app/build.gradle.kts` — `applicationId = "com.ireiter.zual"`; `compileSdk`,
  `minSdk`, `targetSdk`, and `ndkVersion` all inherit from the Flutter Gradle plugin
- `android/gradle.properties` — JVM heap 8G, AndroidX enabled
- `android/key.properties` and `android/upload-keystore.jks` — release signing material.
  **Both are gitignored** (`.gitignore` lines 65–66, 129–130); a fresh clone can build
  debug but not release until they are supplied.

## Platform Requirements

**Development:**
- Flutter SDK (stable) with a Dart SDK satisfying `^3.10.7`
- Android SDK, build tools, and a device or emulator
- No Xcode requirement — there is no `ios/` directory in this repo

**Production:**
- **Android:** the only supported v1 target. Min/target SDK follow the Flutter defaults for
  the pinned SDK; release artifact is an `.aab` produced by `flutter build appbundle --release`.

**Supported Platforms:**
- Android — the sole v1 target
- Web — Flutter's scaffold in `web/` is still present and buildable, but out of scope for
  v1 and unverified; the app is portrait-only and designed for a handheld screen
- iOS — **not configured**; no `ios/` directory exists. Listed as a v2 candidate in
  PROJECT.md (PLAT-01).

## Test and Tooling Surface

- 21 `_test.dart` files plus 4 non-suffixed helpers/generators, ~2,846 LOC, 134 tests;
  `flutter test` and `flutter analyze` both clean as of 2026-08-19
- `test/tool/` holds headless asset generators that render the Play Store icon and feature
  graphic from the app's real `CustomPainter`s via `renderPainterToPng`, so store artwork
  cannot drift from shipping visuals
